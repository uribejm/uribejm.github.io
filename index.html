Bienvenido a la página oficial de la integración de rclone.

¿Qué es esta aplicación?

rclone es una herramienta para la gestión, sincronización y almacenamiento de archivos personal de forma segura. Esta integración permite conectar de manera eficiente servicios de almacenamiento en la nube autorizados por el usuario para respaldos automáticos y transferencia de archivos.

Uso de datos y permisos

Esta aplicación solicita acceso mediante OAuth únicamente para leer y escribir archivos en las carpetas seleccionadas por el usuario, sin compartir información con terceros.
